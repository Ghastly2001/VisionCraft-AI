# Product

## Register

product

## Users

Individual creators and hobbyists editing personal photos — restoring old images, generative fill, removing objects, recoloring. Session context is casual and fast: users land on a screen, run one AI transform, check the result, move on. Low-friction, low-jargon, no professional-workflow assumptions.

## Product Purpose

VisionCraft AI is a credit-based SaaS for AI image transformation (Image Restore, Generative Fill, Object Remove, Object Recolor, background remove). Auth via Clerk, payments via Stripe, media via Cloudinary. Success looks like: a user understands what a tool does at a glance, runs it in as few clicks as possible, and trusts the result enough to use the product again.

## Brand Personality

Clean, precise, technical. Confident and calm rather than playful or loud — the interface should read as a capable tool, not a marketing funnel. One deliberate accent color carries identity; everything else is quiet neutral structure that gets out of the way of the user's images (the images are the visual interest, not the chrome around them).

## Anti-references

The current generic purple/indigo SaaS gradient look: purple hero banner gradient, purple pill buttons, purple-tinted card borders and shadows (`shadow-purple-200/10`), decorative sparkle particles. Reads as templated/AI-generated. Also avoid overcorrecting into the cream/sand "warm neutral" AI tell — use a true neutral or a neutral tinted toward the brand's own accent hue, not warm-by-default.

## Design Principles

- Let the images be the color. Chrome (nav, cards, buttons) stays quiet and neutral; one accent color is used deliberately, not smeared across every surface.
- Structure over decoration. Prefer clear hierarchy, spacing, and type weight over gradients, shadows, and particle effects to establish importance.
- Fast to parse. Every dashboard screen has one primary action; users should never have to hunt for what a tool does.
- Trustworthy, not flashy. Precision and restraint read as credibility for a tool that's about to alter someone's photo.

## Accessibility & Inclusion

WCAG AA: body text ≥4.5:1 contrast, large text/UI elements ≥3:1. Respect `prefers-reduced-motion` for any transitions/animations. No colorblind-specific palette constraints called out beyond standard AA contrast.
